# JT-Zero — вердикт по линейному OpticalFlow bench

Дата: 2026-09-12  
Ветка: `ground-motion-mvp`

## Решение

Линейный bench по метрическому масштабу OpticalFlow закрыт.

Новые серии A→B/B→A с измерением линейкой не выполнять без новой конкретной причины,
возникшей на следующем этапе системы.

## Что подтверждено

Continuous reciprocal серия выполнялась одним процессом камеры/MAVLink/RangeFinder/DataFlash.

Фактические результаты RAW/physical:

- leg 1 A→B: 1.0165
- leg 2 B→A: 1.0055
- leg 3 A→B: 1.0152
- leg 4 B→A: 1.0004
- leg 5 A→B: 1.0074
- leg 6 B→A: 1.0029

Следовательно, текущий RAW OpticalFlow имеет правильный метрический масштаб для bench-условий.
`JTZERO_FLOW_FOCAL_SCALE=1.1060` не менять без новых независимых данных.

RangeFinder в DataFlash оставался около 0.600 м.

## Что осталось у EKF

EKF не воспроизводит RAW идеально во всех динамических проходах.

Критическая пара:

- leg 5, 300 мм: RAW/P=1.0074, EKF/P=0.9998, EKF/RAW=0.9925;
- leg 6, 300 мм: RAW/P=1.0029, EKF/P=1.1015, EKF/RAW=1.0984.

После исправления анализа DataFlash оба EKF3 core показывают для leg 6 примерно одинаковое
горизонтальное перемещение:

- core 0: около 327.0 мм;
- core 1: около 327.5 мм.

То есть эффект находится в состоянии EKF, а не является артефактом смешивания core.

Для leg 5 XKF1 даёт около 298.6 мм, post-stop drift за 1.5 с около 2.8 мм.
Для leg 6 XKF1 даёт около 327.5 мм, post-stop drift за 1.5 с около 13.5 мм.

Основная лишняя дистанция leg 6 накопилась во время движения; post-stop drift не объясняет её полностью.

## Что НЕ доказано

Не доказано, что причиной остаточной динамической ошибки является:

- `EK3_FLOW_DELAY`;
- software-visible camera→send latency;
- HAGL;
- focal scale;
- направление движения само по себе.

Поэтому не менять `EK3_FLOW_DELAY=0` и не корректировать focal scale для компенсации EKF.

## Методологическая граница

Этот остаточный эффект не является основанием продолжать бесконечную метрическую калибровку на линейке.

Следующий этап должен проверять уже целевое поведение системы удержания:
стабильность скорости/позиции при реальном замкнутом контуре и реакцию на малое возмущение.

Возвращаться к линейному bench только если следующий этап покажет конкретный симптом,
который можно однозначно связать с ошибкой RAW OpticalFlow.
