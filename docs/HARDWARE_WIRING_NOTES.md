# JT-Zero — заметки по распиновке оборудования

## TF-Luna

- **RX — чёрный провод / помечен чёрным.**

Это фактически проверенная маркировка конкретного TF-Luna, используемого в текущем стенде JT-Zero. При дальнейших инструкциях по переподключению TF-Luna считать эту маркировку приоритетной и не выводить цвет RX из типовой цветовой схемы кабеля.
